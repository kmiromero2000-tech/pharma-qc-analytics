# Pharma QC Analytics (MSPC + Machine Learning)

Herramienta de analítica basada en control estadístico multivariante (MSPC) y clasificación supervisada para el aseguramiento de calidad en la producción de tabletas farmacéuticas.

## Requisitos
- Docker y Docker Compose

## Despliegue rápido
```bash
docker compose up --build
```

- **Frontend:** http://localhost:3000
- **Backend API Docs (Swagger):** http://localhost:8000/docs
